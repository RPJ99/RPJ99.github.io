# rpj99.github.io

Portfolio site for Roshan Johns, mechanical engineer in medical-device R&D.

- `index.html`: the portfolio page
- `simulator/`: interactive simulator for the microfluidic flow and heat-transfer model
- `assets/`: figures from [microfluidic-thermal](https://github.com/RPJ99/microfluidic-thermal)

Plain static HTML, served by GitHub Pages. No build step.
